# 📖 Claude Project Management Documentation

Índice de documentação gerada automaticamente para rastreamento de projeto, milestones e saúde geral do Snipet.

---

## 🚀 Começando

Bem-vindo ao dashboard de documentação do Snipet! Esta pasta contém toda a documentação de rastreamento do projeto.

### 📋 Documentos Principais

#### 1. **PROJECT_HEALTH.md** 🏥
   - **Descrição:** Dashboard completo da saúde do projeto
   - **Use quando:** Você quer uma visão geral rápida do status
   - **Contém:** 
     - Health score e métricas chave
     - Status de milestones
     - Issues bloqueadores
     - Recomendações de ação
   - **Frequência de Atualização:** Semanal

#### 2. **MILESTONE_STATUS.md** 🎯
   - **Descrição:** Rastreador de status detalhado por milestone
   - **Use quando:** Você precisa ver o progresso de uma milestone específica
   - **Contém:**
     - Progress bars visuais
     - Breakdown completo de issues
     - Prioridades de tarefas
     - Sub-issues e dependências
   - **Frequência de Atualização:** A cada novo progresso

#### 3. **RELEASE_NOTES.md** 📝
   - **Descrição:** Changelog completo e histórico de releases
   - **Use quando:** Você quer entender o que foi mudado em cada versão
   - **Contém:**
     - Release notes por versão
     - Features adicionadas
     - Bugfixes e melhorias
     - Timeline de desenvolvimento
   - **Frequência de Atualização:** Após cada release

#### 4. **../MILESTONES.md** 📦
   - **Descrição:** Overview completo de cada milestone
   - **Use quando:** Você quer entender os objetivos e realizações de cada release
   - **Contém:**
     - Descrição de cada milestone
     - Issues associadas
     - Principais features
     - Roadmap futuro
   - **Frequência de Atualização:** Por milestone

#### 5. **../.github/MILESTONE_DESCRIPTIONS.md** 🔧
   - **Descrição:** Instruções para atualizar milestones no GitHub
   - **Use quando:** Você quer atualizar as descrições das milestones na UI do GitHub
   - **Contém:**
     - Descrições prontas para copiar/colar
     - Instruções passo-a-passo
     - Checklist de atualização
   - **Frequência de Atualização:** Conforme necessário

## ⚡ Atualizações Rápidas

### Como Atualizar Esta Documentação

Após completar trabalho em uma issue:

1. Atualize `MILESTONE_STATUS.md` com novo status
2. Se completou uma milestone, atualizar `PROJECT_HEALTH.md`
3. Quando fazer release, adicionar entry em `RELEASE_NOTES.md`
4. Manter `PROJECT_HEALTH.md` sincronizado com GitHub
