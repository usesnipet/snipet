---
title: Anonymous users
description: Let visitors chat without signing in.
---

1. In **Apps**, open the app, turn on **Allow anonymous** and add your site to **Allowed origins**, like `https://www.example.com`.
2. Pass only `appId` to the widget, no token:

   ```js
   SnipetWidget.init({ apiUrl: "https://snipet.example.com", appId: "<your app id>", agentId: "<your agent id>" });
   ```

The widget creates an anonymous user on the first visit and keeps it in the browser's `localStorage`. The same visitor gets their conversations back on later visits, until they clear their site data or switch browsers.

## Limits

- Requests are only accepted from the app's allowed origins.
- New anonymous users are rate limited per IP: 30 an hour by default (`ANONYMOUS_SIGNUPS_PER_IP_PER_HOUR`).
- Every end user can start 10 runs a minute by default (`AGENT_RUNS_PER_END_USER_PER_MINUTE`).

Anonymous users are fine for public, low-risk agents. If the agent can act on private data, [identify your users](/docs/auth/) instead.
