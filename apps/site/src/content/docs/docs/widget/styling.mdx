Start with the lightest option that does the job.

![Chat widget with custom colors](/images/docs/widget-styled.png)

## Options

`theme`, `size`, `radius`, `primaryColor`, `backgroundColor` and `textColor` cover most sites:

```js
SnipetWidget.init({
  apiUrl,
  appId,
  agentId,
  theme: "auto",
  primaryColor: "#0f766e",
  radius: 8,
});
```

## CSS variables

Set them on `snipet-widget` from your own stylesheet:

```css
snipet-widget {
  --sw-accent: #0f766e;
  --sw-font: "Inter", sans-serif;
}
```

Variables: `--sw-accent`, `--sw-accent-text`, `--sw-surface`, `--sw-text`, `--sw-muted`, `--sw-border`, `--sw-header`, `--sw-header-text`, `--sw-input`, `--sw-shadow`, `--sw-font`, `--sw-radius`, `--sw-scale`.

## Parts

Style specific pieces with `::part()`, for example to move the widget above a cookie banner:

```css
snipet-widget::part(root) {
  bottom: 80px;
}
```

| Part | |
| --- | --- |
| `root` | The fixed container in the corner, holding the panel and the launcher. |
| `launcher` | The button that opens and closes the panel. |
| `panel` | The chat window. |
| `backdrop` | The dimmed page behind the panel, with `size: "full"`. |
| `header` | The panel's top bar. |
| `body` | The scrolling list of messages. |
| `message` | Every chat bubble; also `user` or `assistant`. |
| `thinking` | The agent's collapsed reasoning. |
| `tool` | A plugin call, or a group of them. |
| `waiting` | The status shown while the agent works, like "Thinking". |
| `composer`, `input`, `send` | The message box and its send button. |
| `sessions`, `session` | The chat history list and each chat in it. |

## Custom CSS

For anything else, the `css` and `cssUrl` options load CSS inside the widget's Shadow DOM, where it can restyle any `.sw-*` class. These classes can change between versions, so prefer the options above when they're enough.
